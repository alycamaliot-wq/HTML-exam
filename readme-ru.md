# Многостраничный личный сайт: экзамен / задание по HTML

Практическое задание для обучения **чистому HTML**: семантическая разметка, навигация, формы и ссылки. Учащиеся создают небольшой многостраничный личный сайт **без какого-либо CSS**. Готовый сайт можно потом использовать как основу для **экзамена по CSS**.

---

## 1. Обзор

| | |
|---|---|
| **Предмет** | Основы HTML |
| **Уровень** | Начальный |
| **Длительность** | 60-90 минут (экзамен) или 1-2 урока (задание) |
| **Инструменты** | Любой редактор кода + браузер |
| **Разрешено** | Только HTML. Без CSS, JavaScript и фреймворков |
| **Максимальный балл** | 100 баллов |
| **Проходной балл** | 60 баллов |

---

## 2. Что охватывает задание

Выполняя его, учащиеся показывают, что умеют:

- Использовать **семантические элементы HTML** вместо универсальных тегов `<div>`
- Структурировать контент с правильной **иерархией заголовков** (от `h1` до `h3`)
- Строить **навигацию** как между страницами, так и внутри страницы (якорные ссылки)
- Разделять разделы с помощью уникальных **атрибутов `id`**
- Создавать **форму**, собирающую данные пользователя, с правильными label и типами полей
- Добавлять **внешние ссылки** (соцсети) и контактные ссылки (`mailto:`, `tel:`)
- Организовывать проект в **несколько связанных файлов**

---

## 3. Описание задания (выдайте учащимся)

Создайте личный сайт из **4 HTML-страниц**:

| Страница | Файл | Содержание |
|---|---|---|
| 1 | `index.html` | О себе (часть 1): представление, образование, увлечения |
| 2 | `about2.html` | О себе (часть 2): биография, опыт, цели |
| 3 | `skills.html` | Что вы умеете: навыки, услуги, проекты |
| 4 | `contact.html` | Контактная форма + ссылки на соцсети |

На каждой странице должны быть одинаковые навигация и подвал, и с любой страницы должна быть возможность перейти на все остальные.

**Ограничения:** не используйте CSS (никаких `<style>`, `style=""`, файлов `.css`) и JavaScript.

---

## 4. 20 требований (критерии оценивания)

Каждое требование стоит **5 баллов**. Всего: **100**. Проходной балл: **60 и выше** (12 требований).

### A. Структура и семантика (25 баллов)

| # | Требование | Баллы |
|---|---|---|
| 1 | На каждой странице корректный каркас: `<!DOCTYPE html>`, `<html lang>`, `<head>`, `<meta charset>`, `<title>`, `<body>` | 5 |
| 2 | У каждой страницы **уникальный и осмысленный `<title>`** | 5 |
| 3 | На каждой странице используются семантические элементы: `<header>`, `<nav>`, `<main>`, `<footer>` | 5 |
| 4 | Контент сгруппирован через `<section>` и `<article>` там, где это уместно (а не `<div>` везде) | 5 |
| 5 | На каждой странице ровно **один `<h1>`** | 5 |

### B. Заголовки и контент (20 баллов)

| # | Требование | Баллы |
|---|---|---|
| 6 | Заголовки соблюдают иерархию (`h1` > `h2` > `h3`), уровни не пропущены | 5 |
| 7 | На страницах 1 и 2 есть реальная информация об учащемся (имя, образование, биография, цели) | 5 |
| 8 | На странице 3 описано, что умеет учащийся (навыки, услуги или проекты) | 5 |
| 9 | Использован минимум **один список** (`<ul>` или `<ol>`) и **одна таблица** с `<thead>` / `<tbody>` | 5 |

### C. Навигация и ID (25 баллов)

| # | Требование | Баллы |
|---|---|---|
| 10 | На каждой странице есть **основная навигация** (`<nav>` со списком ссылок) | 5 |
| 11 | Ссылки основной навигации работают между всеми 4 страницами (нет битых ссылок) | 5 |
| 12 | У каждого `<section>` есть **уникальный `id`**, описывающий его содержание | 5 |
| 13 | Есть минимум **одна навигация внутри страницы** с якорными ссылками (`href="#id"`), ведущими к этим id | 5 |
| 14 | Для перехода со страницы на страницу есть ссылки **Далее / Назад**, а также ссылка «Наверх» | 5 |

### D. Форма (20 баллов)

| # | Требование | Баллы |
|---|---|---|
| 15 | В `contact.html` есть `<form>` с атрибутами `action` и `method` | 5 |
| 16 | У каждого поля есть соответствующий `<label for="...">` и атрибут `name` | 5 |
| 17 | Использовано минимум **4 разных типа полей** (например `text`, `email`, `tel`, `number`, `date`, `radio`, `checkbox`) | 5 |
| 18 | Есть `<select>` или `<textarea>`, **кнопка отправки** и хотя бы одно поле `required` | 5 |

### E. Ссылки и контакты (10 баллов)

| # | Требование | Баллы |
|---|---|---|
| 19 | Ссылки минимум на **3 соцсети** (Instagram, Telegram, WhatsApp и т.д.) открываются в новой вкладке (`target="_blank"`) | 5 |
| 20 | В контактных данных использованы ссылки `mailto:` и `tel:`; на каждой странице есть подвал | 5 |

## 6. Структура эталонного решения

```
my-website/
├── index.html      → Обо мне (1): #intro, #education, #hobbies
├── about2.html     → Обо мне (2): #background, #experience, #goals
├── skills.html     → Что я умею: #skills, #services, #projects
└── contact.html    → #contact-form, #socials
```

### Минимальный шаблон страницы

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Обо мне - Страница 1</title>
</head>
<body id="page-about-1">

  <header id="site-header">
    <h1>Имя учащегося</h1>

    <nav id="main-nav" aria-label="Основная навигация">
      <ul>
        <li><a href="index.html">Обо мне (1)</a></li>
        <li><a href="about2.html">Обо мне (2)</a></li>
        <li><a href="skills.html">Что я умею</a></li>
        <li><a href="contact.html">Контакты</a></li>
      </ul>
    </nav>
  </header>

  <main id="main-content">
    <section id="intro">
      <h2>Представление</h2>
      <p>...</p>
    </section>
  </main>

  <footer id="site-footer">
    <p>&copy; 2026 Имя учащегося</p>
  </footer>

</body>
</html>
```

### Минимальный пример формы

```html
<form action="#" method="post" id="form-contact">
  <p>
    <label for="fullname">Полное имя:</label>
    <input type="text" id="fullname" name="fullname" required>
  </p>
  <p>
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>
  </p>
  <p>
    <label for="message">Сообщение:</label>
    <textarea id="message" name="message" rows="5"></textarea>
  </p>
  <button type="submit">Отправить</button>
</form>
```

## 7. Как преподаватели могут это использовать

1. **Как экзамен:** выдайте учащимся раздел 3 (задание), а раздел 4 (критерии) оставьте для проверки.
2. **Как пример на уроке:** покажите эталонное решение и разберите каждое требование.
3. **Для самопроверки:** дайте учащимся критерии, чтобы они оценили свою работу перед сдачей.
4. **Как основа для экзамена по CSS:** сохраните HTML учащихся и попросите оформить его стилями. Поскольку у каждого раздела есть уникальный `id`, можно отработать селекторы `#id`, вёрстку `header` / `nav` / `main` / `footer`, оформление форм, таблиц и списков и т.д.

- [ ] Все 4 файла существуют и открываются в браузере
- [ ] CSS / JS не использованы
- [ ] На каждой странице одинаковые навигация и подвал
- [ ] Id разделов уникальны, якорные ссылки работают
- [ ] В форме есть label, разные типы полей и кнопка отправки
- [ ] Ссылки на соцсети открываются в новой вкладке

## 8. Частые ошибки учащихся

| Ошибка | Почему это важно |
|---|---|
| Использование `<div>` для всего | Теряется смысл семантического HTML |
| Несколько `<h1>` на странице | Нарушается иерархия заголовков |
| Выбор уровня заголовка по размеру | Заголовки описывают структуру, а не внешний вид |
| Повторяющиеся значения `id` | Id должны быть уникальны на странице |
| Поля без `<label>` | Ухудшается доступность |
| Неверные относительные пути | Файлы должны лежать в одной папке |
| Оставленный шаблонный текст (`[Ваше имя]`) | Контент не заполнен |
